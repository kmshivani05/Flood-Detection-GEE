\# Flood Detection using Google Earth Engine (Python)



This project detects flood-affected areas using Sentinel-1 SAR data.



\## Features

\- Before vs After analysis

\- Flood detection using backscatter thresholding

\- Noise removal and smoothing

\- Flood area estimation



\## Tech Stack

\- Google Earth Engine

\- Python

\- Geemap



\## Output

Flood Area: \~554 sq km (Assam region)



\## How to Run

1\. Install dependencies

2\. Authenticate Earth Engine

3\. Run the script
